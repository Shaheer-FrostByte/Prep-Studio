📐 Input formats

Copy these into your AI so it generates questions in the right shape.

MCQ 
[
  {
    "question": "...",
    "options": ["A", "B", "C", "D"],
    "answer": 1 (1-based index)
  }
]
answer is the number of the correct option, starting at 1 (1 = first option).
Flashcards 
[
  {
    "front": "Term",
    "back": "Definition"
  }
]
Short Q&A (input) 
[
  {
    "question": "What is ...?",
    "ai_answer": "A short, clear answer (optional)"
  }
]
ai_answer is optional. If included, it is shown next to the user's answer after finishing.

✍️ Short Q&A step by step

  1. Ask your AI for questions in the input format above.
  2. Paste the JSON into the Short Q&A page and click Start.
  3. Answer each question in the text box. Use Previous and Next to move around.
  4. Finish by clicking Finish & Generate Output.
  5. Compare (when questions include an ai_answer): the user's answer and the AI generated answer are shown side by side.
  6. Copy the output (it includes a built-in instruction) and paste it straight into your AI. No extra typing needed.

Output example

Output with instruction 
{
  "instruction": "Review the user's answers. Mark each as correct/incorrect. If incorrect, provide the correct answer or a brief explanation.",
  "qa_pairs": [
    {
      "question": "...",
      "user_answer": "..."
    }
  ]
}
