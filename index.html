⚡ The 3‑Step Workflow

1. Generate
Ask your AI to create questions in the required JSON format.
2. Paste & Start

3. Interact / Export
Take the quiz, flip cards, or answer questions – then copy the output.

📐 Input Schemas (copy‑paste into your AI)

Flashcards

Short Q&A (input)

✍️ Short Q&A – Step‑by‑Step

  1. Ask your AI for questions in the input schema above.
  2. Paste the JSON into the Short Q&A page and click Start.
  3. Answer each question in the multi‑line box – use Prev/Next.
  4. Finish – click Finish & Generate Output.
  5. Copy the entire output JSON (it includes a built‑in instruction) and paste it directly into your AI – no extra typing needed.
Output example (with instruction): 
{
  "instruction": "Review the user's answers. Mark each as correct/incorrect. If incorrect, provide the correct answer or a brief explanation.",
  "qa_pairs": [
    {"question":"...","user_answer":"..."}
  ]
}
